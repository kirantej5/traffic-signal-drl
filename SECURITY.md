# Security Policy

## Supported versions

The `main` branch is the supported version for security fixes.

## Reporting a concern

Please do not publish credentials, private traffic data, or unsafe model artifacts in a public issue. Report security concerns privately through the repository owner's GitHub contact options and include:

- A concise description of the issue
- Reproduction steps or a minimal proof of concept
- The affected file or workflow
- Any suggested mitigation

Do not include secrets in experiment logs, model checkpoints, or issue attachments.
