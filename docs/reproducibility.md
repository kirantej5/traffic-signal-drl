# Reproducibility and Artifact Provenance

## Scenario provenance

The traffic scenarios in `data/` are generated with SUMO tooling from the scripts in the same directory. They are synthetic 4×4 neighborhood networks with generated peak/off-peak demand. No private or external patient/driver dataset is used by this repository.

- `generate_neighborhood.py` creates the neighborhood network and demand.
- `generate_scenario.py` creates the smaller intersection scenario.
- `.net.xml`, `.rou.xml`, and `.sumocfg` files are committed examples of generated inputs.

## Model provenance

`models/mappo/mappo_traffic_final.pt` is the tracked final checkpoint used by the README evaluation command. Periodic checkpoints and multi-seed experiment checkpoints are ignored under `models/checkpoints/` because they are generated artifacts. Recreate them with:

```bash
python src/train_marl.py --seed 42 --episodes 15 --max-steps 1800 --model-dir models/checkpoints/seed_42
```

For larger artifacts, use a GitHub Release, Git LFS, or an external artifact registry instead of committing generated weights directly to the source tree.

## Results provenance

- Tracked CSV files under `results/` are example outputs from the commands described in the README.
- The five-seed exploratory study is recorded in `results/marl/statistical_analysis/per_seed_results.csv` and `paired_t_test.json`.
- Per-run logs, plots, and temporary checkpoints from that study are ignored and can be regenerated with `scripts/run_statistical_analysis.py`.
- Reported metrics depend on SUMO version, generated demand, random seed, evaluation horizon, and controller checkpoint. Always record those values with new results.

## Environment

Use Python 3.11 or 3.12, SUMO 1.28+, and either the flexible requirements or the tested direct pins:

```bash
pip install -r requirements.txt -c requirements-pinned.txt
```

## Software and scenario citations

The simulation engine is Eclipse SUMO. Cite the SUMO project when using the generated scenarios or results:

> Pablo Alvarez Lopez et al. (2018). *Microscopic Traffic Simulation using SUMO*. IEEE Intelligent Transportation Systems Conference (ITSC). <https://doi.org/10.1109/ITSC.2018.8569938>

The neighborhood demand and network are synthetic outputs generated by this repository; there is no external traffic dataset citation to add. Cite this repository using [`CITATION.cff`](../CITATION.cff) for the MAPPO, GNN, routing, and evaluation implementation.
